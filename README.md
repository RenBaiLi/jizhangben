# 家庭记账本 (PWA)

两口子共用的记账本网页应用：按月记录工资/支出/其他收入，自动算结余，可导出 Excel。

## 功能

- 媳妇工资、我的工资、其他收入（多笔，带来源）
- 每笔支出可写备注，按人分类统计
- 自动算本月结余，下月自动结转（含跨年）
- 年度 12 个月一览
- 一键导出 Excel（年度汇总 + 12 个月明细 + 使用说明）
- 数据存本机浏览器，支持 JSON 备份/恢复
- 支持"添加到主屏幕"，全屏运行、离线可用

## 部署（Gitee Pages）

1. 仓库设为**公开**
2. 仓库 → 服务 → **Gitee Pages** → 选择 `main` 分支、部署目录填 `/`（根目录）→ 启动
3. 得到 `https://<用户名>.gitee.io/<仓库名>/` 网址

## 安装到 iPhone

Safari 打开网址 → 分享按钮 → **添加到主屏幕**

## 本地开发

```bash
python -m http.server 8765
# 打开 http://localhost:8765
```
